📄 Tải Lên Tài Liệu (chỉ chấp nhận file PDF)

Hệ thống áp dụng phân quyền upload theo từng Phòng ban mà bạn được phân công. Mã tài liệu và phiên bản do hệ thống tự sinh.

✉️ Cấu Hình Server Email Thông Báo (SMTP Server)

Cấu hình mail hệ thống dùng để thông báo tự động khi phát sinh tài liệu cần duyệt.

🔑 Cấu Hình Đăng Nhập LDAP / Active Directory

Đăng nhập sẽ thử mật khẩu local trước; nếu sai và LDAP đang bật, hệ thống thử xác thực qua AD với cùng tài khoản/mật khẩu. Username phải đã tồn tại sẵn trong DMS (mục Quản Lý Người Dùng) — LDAP không tự tạo tài khoản mới.

🗂️ Đồng Bộ Tài Khoản AD (module Tài khoản AD)

Dùng LDAP Server URL ở trên. Tài khoản dịch vụ cần quyền duyệt (search) thư mục trong Base DN. Hệ thống tự đồng bộ hàng ngày, có thể bấm "Đồng bộ ngay" ở tab Tài khoản AD để chạy thử ngay.

🏢 Quản Lý Phòng Ban

Viết tắt dùng để tự sinh mã tài liệu (VD: IT, NS...), chỉ chữ/số không dấu, tối đa 10 ký tự.
